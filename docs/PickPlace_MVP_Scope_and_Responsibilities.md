### FE 완료 기준

- 사용자가 지역과 업종을 선택할 수 있다.
- 선택한 조건으로 분석 API를 호출할 수 있다.
- 지도, 차트, 점수 및 영향 요인이 실제 데이터로 표시된다.
- 로딩, 오류, 데이터 부족 상태를 구분해서 보여준다.
- 주요 화면이 모바일과 데스크톱에서 정상적으로 동작한다.

### BE 완료 기준

- 정제된 상권 데이터가 DB에 저장되어 있다.
- FE에서 사용할 지역·업종·현황·추이 API가 동작한다.
- AI 서버에 필요한 특징값을 전달할 수 있다.
- AI 결과와 통계 데이터를 하나의 응답으로 제공한다.
- AI 서버가 실패해도 전체 서비스가 중단되지 않는다.
- Swagger 또는 별도 문서로 API 명세가 정리되어 있다.

| API 개발 | 모델 정보 API | 모델 버전과 학습 정보 반환 | `GET /model-info` | 권장 | BE |
| API 개발 | 예측 API | 특징값을 받아 점수와 영향 요인 반환 | `POST /predict` | 필수 | BE |
| API 개발 | 입력값 검증 | 필수 특징값, 데이터 타입 및 범위 검증 | Pydantic 요청 모델 | 필수 | BE |
| 최적화 | 모델 사전 로딩 | 서버 시작 시 모델을 한 번만 메모리에 로딩 | 초기화 로직 | 필수 | 인프라 |
| 최적화 | 메모리 관리 | Worker 수 제한 및 모델 크기 최적화 | 배포 설정 | 필수 | 인프라 |

| 배포 | 컨테이너 구성 | FastAPI, 전처리 Pipeline, 모델을 이미지로 구성 | AI Docker 이미지 | 필수 | 인프라 |
| 문서화 | 모델 카드 작성 | 모델 목적, 데이터, 성능, 한계 및 주의사항 기록 | 모델 카드 | 권장 | 전체 |

### AI 완료 기준

- 성장성·위험도·적합도 계산 기준이 정의되어 있다.
- 전처리부터 예측까지 동일한 Pipeline으로 실행된다.
- 기준 모델과 최종 모델의 성능 차이가 검증되어 있다.
- 테스트 데이터 기준 성능이 문서화되어 있다.
- FastAPI가 점수, 등급, 신뢰도 및 영향 요인을 반환한다.
- 모델 버전과 학습 데이터 기준 시점을 확인할 수 있다.
- 데이터가 부족한 경우 낮은 신뢰도 또는 분석 불가를 반환한다.
